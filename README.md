# TwinCloud – Dashboard prototype

Clickable prototype of the TwinCloud dashboard for planning recordings on site (tablet, touch, outdoors).
Design source: Figma "NEW TwinCloud", dashboard `1818:48845` and upload dialog `1835:11994`.

**Open it:** https://csinghtwin.github.io/twincloud-dashboa/Dashboard.html, or download `Dashboard.html` and open it in a browser. It's a single file with every image, icon and font built in.

## What you can try
- Pick a building in the list on the left, or add one with **+** (street + house numbers as chips).
- **Mark as done** on a placeholder; every change shows a toast with **Undo** (5 s).
- **⋮** on a card (or Shift+F10 on a focused card): edit name, add part 2, change time, mark as bad take, reset.
- **+ Add extra** for things like a bike stand.
- **Upload files**: camera recordings are matched to placeholders and renamed, e.g.
  `CAM_20261105153812_0004_D.OSV → Inside_Wedellstraße 6.OSV`. Drag to fix a match, then upload.

All data is sample data and lives only in the page; nothing is saved or sent anywhere.
